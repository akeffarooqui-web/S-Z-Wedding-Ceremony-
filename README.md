# Saba Mahek & Mohammed Zaid — Wedding Invitation

## Files
- `index.html` — website content
- `styles.css` — colors and design
- `script.js` — countdown, opening animation, navigation, RSVP and music button
- `wedding-couple.png` and `wedding-artwork.png` — image assets (keep beside `index.html`)
- `jashn-e-bahaara.mp3` — optional song file; add only a copy you have the right to use.

## GitHub Pages
Upload all files into the repository root (`index.html`, `styles.css`, `script.js`, both PNG images). In Settings → Pages, select `Deploy from a branch`, branch `main`, folder `/(root)`, then Save.

## Music note
This project does not include the copyrighted song recording. To use it, upload a legally obtained/licensed MP3 named exactly `jashn-e-bahaara.mp3` into the same folder as `index.html`. Modern browsers block sound autoplay before a visitor interacts, so the music starts when the visitor presses the music button.
